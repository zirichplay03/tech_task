# Linked List Serialization (C++)

## 📌 Описание

Программа реализует:

* построение двусвязного списка с дополнительным указателем `rand`
* сериализацию списка в бинарный файл
* десериализацию обратно
* проверку корректности через вывод в консоль

---

## 📂 Входные данные

Программа читает файл:

```
intel.in
```

Формат каждой строки:

```
<data>;<rand_index>
```

### Пример:

```
A;2
B;0
C;1
D;-1
```

### Объяснение:

* `data` — строковое значение узла
* `rand_index` — индекс узла, на который указывает `rand`
* `-1` — отсутствие ссылки (`nullptr`)

---

## ⚙️ Сборка и запуск

```bash
mkdir build
cd build
cmake ..
make
```

---

## ▶️ Что делает программа

1. Читает `intel.in`
2. Создаёт двусвязный список
3. Сериализует его в файл `outlet.out`
4. Десериализует обратно
5. Выводит результат в консоль

---

## 🖥️ Пример вывода

```
Loaded nodes: 4
Serialized to outlet.out
Deserialized list:
A -> rand: C
B -> rand: A
C -> rand: B
D -> rand: null
DONE
```

## ⚠️ Возможные ошибки

### ❌ Cannot open input file

Причина:

* файл `intel.in` не найден

Решение:

* убедись, что файл лежит в рабочей директории

---

## ✅ Проверка корректности

После выполнения:

* порядок элементов должен сохраняться
* `rand` должен указывать на те же значения
